É a inteligência do programa. Serve para o código tomar decisões sozinho com base em regras que tu defines. Sem isso, o programa é só uma lista estática de tarefas.

Operadores Relacionais (As Comparações)
É como o JS compara valores. Os principais são:

== e ===: O primeiro ignora o tipo, o segundo é rigoroso (compara valor e tipo). Usa sempre === para evitar erros.

!= e !==: Diferente de.

> , < , >= , <= : Maior, menor, maior ou igual, menor ou igual.

Operadores Lógicos (Combinando condições)
&& (E): Só é verdade se tudo for verdade.

|| (OU): É verdade se pelo menos um for verdade.

! (NÃO): Inverte o valor. O que é verdade vira falso e vice-versa.

 Estrutura IF / ELSE
if (se): Verifica a condição entre parênteses. Se for verdade, executa o que está entre as chaves {}.

else if (senão se): Serve para testar uma segunda condição caso a primeira tenha falhado.

else (senão): É o "plano B". Só roda se todas as condições anteriores forem falsas.

Regras de Sintaxe
O JS diferencia maiúsculas de minúsculas (IF não funciona, tem de ser if).

A condição fica sempre entre parênteses ().

O bloco de código que vai ser executado fica entre chaves {}.
