JS é o motor: HTML é o osso, CSS é a roupa e o JS é o que faz a parada funcionar de verdade.

Alert:Só serve pra avisar algo e irritar o usuário até ele clicar em OK.

Prompt: A pergunta. O usuário digita, o JS guarda. Fica esperto: ele sempre entende o que foi digitado como texto. Se for número, tem que converter depois.

Variáveis (Onde o dado mora):

var:, evita usar pra não dar erro maluco no código.

let:usa quando o valor vai mudar (tipo um contador).

const:Começa tudo com const. Se der erro porque tentou mudar, aí sim você troca pra let.

Tipagem: O JS é "de boa". Ele saca sozinho se é número ou texto, mas você precisa saber a diferença pra não tentar somar "2" + 2 e dar "22".

Resumo: declarar com const, interagir com prompt e não esquecer que o JS diferencia letra maiúscula de minúscula.
