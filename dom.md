Selecionar Elementos (Os principais)
Para mexer em algo, primeiro tens de o "pegar":

getElementById: Pega um elemento pelo ID (único).

querySelector: É o mais versátil. Podes usar seletores de CSS (como .classe ou #id).

Mudar o Conteúdo
textContent: Para mudar apenas o texto de uma tag.

innerHTML: Para inserir código HTML completo lá dentro.

style: Para mudar o CSS direto pelo JS (ex: elemento.style.color = "red").

Eventos (Ação e Reação)
É o que faz o site "ouvir" o usuário. Os mais comuns:

click: Quando alguém clica num botão ou link.

submit: Quando um formulário é enviado.

mouseover: Quando o mouse passa por cima de algo.

keydown: Quando uma tecla é pressionada.

Funções
Serve para guardar um bloco de código e usá-lo várias vezes sem ter de reescrever tudo. No momento, o foco é usá-las para organizar o código.

Revisão de IF/ELSE
O slide reforça: if para a primeira condição, else if para condições extras e else para quando nada mais deu certo.
